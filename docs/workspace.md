# Tango Workspace Spec

**Status: Draft v0.1** — 这是工作区与面板交互的草案，欢迎在 issue 里讨论。

## 1. 目标

工作区是一个可以自由拼接的多面板空间：

- 面板数量不限，可增可减。
- 支持平铺、分屏、标签页、拖出成独立系统窗口。
- 面板可以编组：组内共舞，组外独舞。
- 布局按工作区持久化，下次打开恢复原样。
- 支持多显示器。

## 2. 面板类型

| 类型 | 作用 |
| --- | --- |
| DSH pane | DSH 原生会话 |
| Agent pane | Claude Code、Codex 等 agent 的受管理视图 |
| Terminal pane | 普通 shell，真 PTY |
| Conductor pane | 只读的 canonical timeline，显示谁在第几轮执行、交接了什么 |
| Message Bus pane | 可选，查看独舞面板之间的消息队列 |

## 3. 面板结构

```text
┌─ Claude Code ────────────── 共舞 ── [□] [x] ┐
│  Opus · high effort        running 00:42    │
├─────────────────────────────────────────────┤
│                                             │
│   ... 对话 / 工具调用 / 终端输出 ...          │
│                                             │
├─────────────────────────────────────────────┤
│  > 输入，或点另一块面板接棒                   │
└─────────────────────────────────────────────┘
```

- **头部**：agent 名称、模型 / harness、共舞或独舞标记、状态、最大化 / 分屏 / 拖出 / 关闭。
- **中间**：对话、工具活动或终端输出。
- **底部**：输入框或状态栏；共舞时非执行者显示「等待接棒」。

### 面板状态

- `idle` — 空闲
- `running` — 正在执行，显示耗时
- `waiting-user` — 等待审批或输入
- `waiting-handoff` — 共舞中等待接棒
- `error` — 错误，可重试或 rollover
- `disconnected` — CLI 进程不在

## 4. 布局模型

### 平铺

- 用一棵 split tree 表示：水平/垂直分割，分隔线可拖动。
- 面板头部可拖动换位置；拖动时显示停靠区域（左/右/上/下/中间）。
- 双击头部最大化，再双击还原。
- 面板可收起、关闭、重新打开。

### 标签页

- 一个窗格可以承载多个会话，以标签页切换。
- 标签可拖动排序，也可以拖出成新窗格或独立窗口。
- 新建面板时可以选择「新窗格」或「当前窗格的新标签页」。

### 独立系统窗口

- 任意面板可以拖出成独立 OS 窗口，或通过菜单选择「在新窗口打开」。
- 独立窗口记住自己的显示器、位置和大小。
- 可以拖回主窗口重新停靠。
- 主窗口关闭时的行为待定（见开放问题）。

### 持久化

- 每个工作区保存一份布局 JSON：split tree、标签页、独立窗口、显示器、面板到会话的映射。
- 重启后恢复布局；会话能恢复就恢复，不能恢复就提示重新连接。

## 5. 交互

### 鼠标

- 拖分隔线：调整大小。
- 拖面板头部：换位置、重新停靠。
- 双击头部：最大化 / 还原。
- 右键头部：分屏、拖出、关闭、编组。
- 拖消息卡片到另一个面板：发送给那个 agent。
- 拖文件到面板：作为附件或路径传入。

### 键盘（计划）

- 聚焦上/下/左/右面板。
- 拆分当前面板。
- 关闭当前面板。
- 在面板之间循环。
- 把当前面板拖出成独立窗口。
- 新建标签页 / 切换标签页。

### 编组

- 选中多个面板，选择「连接」；同一组共用边框颜色和会话账本。
- 组内任意面板可以发起回合。
- 可以把面板从组里移出，或解散组。
- 一个工作区可以同时存在多个共舞组和若干独舞面板。

## 6. 模式表现

### 共舞组

- 同组面板同色边框或角标。
- 当前执行者的头部亮「接力棒」。
- 非执行者只读，消息标注 `executed by <agent>`。
- 切换时显示「正在补交离开期间的记录」，完成后恢复输入。
- Conductor 面板显示 canonical timeline、回合归属和 handoff 记录。

### 独舞

- 每个面板独立边框、独立会话。
- 「发给谁」菜单或拖拽卡片投递消息。
- 对方忙时消息进入队列，显示排队徽标。
- 人随时可以点进任意面板接管。

### 混用

- 同一工作区可同时有共舞组和独舞面板。
- 面板可以在「共舞组」和「独舞」之间移动；移动前提示会改变会话归属。

## 7. 状态与反馈

- 运行中：spinner + 耗时。
- 等待审批：头部高亮 + 通知。
- 交接中：显示补交的消息数量。
- 失败：显示原因，提供重试 / 新建原生会话。
- 消息队列：显示未读和排队数量。
- 断线：面板保留最后状态，可重连。

## 8. 可访问性

- 键盘可达所有面板操作。
- 清晰的焦点环。
- 屏幕阅读器标签。
- 减少动效选项。
- 高对比度主题。

## 9. 开放问题

- 主窗口关闭时，独立窗口里的会话是否继续运行？
- 标签页和窗格的边界：同一 agent 的多个会话应该开标签还是开窗格？
- 共舞组能否跨独立窗口？
- 面板数量上限和性能边界。
- 拖拽消息到共舞组时的语义：是发给当前执行者，还是写入 canonical history？
- 布局文件与 DSH 工作区配置的关系。
