# Tango 工作区规格

设计草案。Tango 作为独立应用启动，负责加载工作区，并通过 Adapter 连接已有 Agent 的原生会话。

## 0. 当前实现（与首版设计的差距）

已实现：项目目录与最近项目切换、任务（新建 / 重命名 / 复制 / 归档 / 恢复 / 删除 / 置顶 / 拖拽排序 / 搜索、行内快捷操作）、任务记录与原生会话引用、终端画布（标签、分屏、布局恢复、shell 重命名）、四个 Agent 的发送与中断、Codex 与 DSH 审批转发、Markdown 展示、每回合工具活动（折叠成一行并随回复保存）、回合分隔（交接与长时间停顿）、交接（按 Agent 标记最近回合并附上所用工具）、会话内查找、后台回合继续写入并标记未读、设置（主题、强调色、终端 shell、默认 Agent、Codex 审批与沙箱、版本与平台）、命令面板与斜杠命令、失败回合与重发（Retry / Resend）、输入框上方的回合状态行、按任务保存的草稿与侧栏草稿标记、失败回合的侧栏提示、会话查找高亮、长会话与长消息滚动、三页布局（首页 / 任务页 / 终端页，Ctrl 2 / 3 / 1，Ctrl Shift J 可选分屏）、工具调用三档显示（全部 / 只失败 / Zen）、命令退出码、运行中排队发送、大段粘贴存为附件、窗口标题带运行与审批状态、交接包含失败回合、应用内删除确认、置顶分组与最近项目任务数。

未实现：Claude Code 与 Pi 的审批转发、同一任务的多 Agent 回合互斥的完整验证（真实 CLI 侧）、工具审批的真实流程验证、任务级回合状态跨重启恢复（只在主进程写盘时恢复）。

## 1. 工作区、任务与 Agent

| 对象 | 管理内容 |
| --- | --- |
| 工作区 | 项目目录、任务列表、Agent 配置引用、面板布局 |
| 任务 | 目标、对话、参与的 Agent、执行者、回合状态、改动摘要、待办和交接记录 |
| Agent 接入 | 显示名称、对应的 Adapter、原生连接配置与可用会话操作。 |
| 面板 | 当前显示的任务与 Agent，可关闭后重新打开 |

任务属于工作区。共舞时，同一任务可关联多个 Agent 面板，所有面板读取同一份任务时间线。布局按工作区保存，任务记录与布局分别恢复。

## 2. 首版操作

1. 启动 Tango，选择项目目录并连接已安装的 Agent。需要登录时，按该 Agent 的原生流程完成登录。
2. 打开或创建任务，选择已接入的 Agent，提交指令。
3. 对话面板显示回复及 Adapter 提供的工具活动。支持审批转发时，用户可以在面板同意或拒绝请求。支持中断时，可停止当前回合。
4. 需要交接时，在当前回合结束后选择同一任务的下一位 Agent。正在执行时可以先停止，再从已保存的记录接手。
5. 应用重启后恢复任务和已保存的记录，并按 Adapter 能力恢复原生会话。无法确认的回合状态在时间线上标明，用户可根据记录继续任务。

## 3. 任务模式

### 独舞 / Solo

一个任务由一个 Agent 执行。同一工作区可以有多个独立任务。跨任务消息作为后续能力设计，由用户主动发送，对方忙碌时排队投递。

### 共舞 / Unified

多个 Agent 参与同一个任务，同一时间由一位 Agent 执行。其他面板显示共享时间线和当前执行者。交接时，Tango 提供任务目标、此前的决定、已完成回合、已观察到的工作结果和待办，并标明各段记录的来源。已有会话在确认连续性的前提下接收离开期间新增的记录。

交接失败时显示原因，并允许重试或为目标 Agent 建立新会话。新执行者成功接手后，时间线记录本次交接。跨 Agent 的外部权限与会话约定见 [Adapter 协议](adapter-spec.md)。

## 4. 面板

| 面板 | 内容 |
| --- | --- |
| Agent | 对话、执行状态、工具活动、输入与停止操作 |
| 任务时间线 | 回合、执行者、工具结果和交接记录 |
| 终端（后续） | 项目目录下的独立终端 |
| 消息队列（后续） | 独舞任务间的排队和投递状态 |

面板标题显示 Agent 名称、任务和状态。状态包括空闲、执行中、等待审批或输入、交接中、已中断、失败与断线。错误信息应说明失败的操作和可用的恢复动作。

## 5. 布局演进

- 首版采用单窗口，支持任务列表、Agent 面板和任务时间线。
- 后续支持平铺、水平与垂直分屏。拖动分隔线调整大小，拖动面板标题重新停靠，双击标题最大化或还原。
- 同一窗格可用标签页放置多个面板。标签页可排序，也可拖出成为新窗格或独立窗口。
- 独立窗口保存所属工作区、显示器、位置和大小，可拖回主窗口。
- 布局记录包含分屏结构、标签与面板到任务的映射。布局恢复与 Agent 会话恢复分别反馈状态。
- 面板操作支持键盘访问、可见焦点与屏幕阅读器标签。布局快捷键覆盖聚焦、分屏、关闭与标签切换。

独立窗口的生命周期、跨窗口共舞和多面板性能边界待定。
