# Tango 工作区规格

设计草案。Tango 作为独立应用启动，负责加载工作区和启动自身的 Agent 运行时。

## 1. 工作区、任务与 Agent

| 对象 | 管理内容 |
| --- | --- |
| 工作区 | 项目目录、任务列表、Agent 配置引用、面板布局 |
| 任务 | 目标、对话、参与的 Agent、执行者、回合状态、改动摘要、待办和交接记录 |
| Agent 配置 | 名称、角色指令、模型、可用工具与权限。外部 Agent 配置关联其 Adapter。 |
| 面板 | 当前显示的任务与 Agent，可关闭后重新打开 |

任务属于工作区。共舞时，同一任务可关联多个 Agent 面板，所有面板读取同一份任务时间线。布局按工作区保存，任务记录与布局分别恢复。

## 2. 首版操作

1. 启动 Tango，选择项目目录并配置模型。
2. 打开或创建任务，选择一个 Tango Agent，提交指令。
3. 对话面板显示回复和工具活动。需要审批时显示待审批操作，用户可以同意、拒绝或停止当前回合。
4. 需要交接时，在当前回合结束后选择同一任务的下一位 Agent。正在执行时可以先停止，再从已保存的记录接手。
5. 应用重启后恢复任务与已保存的记录。上次退出时仍在执行的回合按中断处理，用户可根据记录继续任务。

## 3. 任务模式

### 独舞 / Solo

一个任务由一个 Agent 执行。同一工作区可以有多个独立任务。跨任务消息作为后续能力设计，由用户主动发送，对方忙碌时排队投递。

### 共舞 / Unified

多个 Agent 参与同一个任务，同一时间由一位 Agent 执行。其他面板显示共享时间线和当前执行者。交接时，Tango 提供任务目标、此前的决定、已完成回合、已观察到的工作结果和待办，并标明各段记录的来源。已有会话在确认连续性的前提下接收离开期间新增的记录。

交接失败时显示原因，并允许重试或为目标 Agent 建立新会话。新执行者成功接手后，时间线记录本次交接。跨 Agent 的外部权限与会话约定见 [Adapter 协议](adapter-spec.md)。

## 4. 面板

| 面板 | 内容 |
| --- | --- |
| Agent | 对话、执行状态、工具活动、输入与停止操作 |
| 任务时间线 | 回合、执行者、工具结果和交接记录 |
| 终端（后续） | 项目目录下的独立终端 |
| 消息队列（后续） | 独舞任务间的排队和投递状态 |

面板标题显示 Agent 名称、任务和状态。状态包括空闲、执行中、等待审批或输入、交接中、已中断、失败与断线。错误信息应说明失败的操作和可用的恢复动作。

## 5. 布局演进

- 首版采用单窗口，支持任务列表、Agent 面板和任务时间线。
- 后续支持平铺、水平与垂直分屏。拖动分隔线调整大小，拖动面板标题重新停靠，双击标题最大化或还原。
- 同一窗格可用标签页放置多个面板。标签页可排序，也可拖出成为新窗格或独立窗口。
- 独立窗口保存所属工作区、显示器、位置和大小，可拖回主窗口。
- 布局记录包含分屏结构、标签与面板到任务的映射。布局恢复与 Agent 会话恢复分别反馈状态。
- 面板操作支持键盘访问、可见焦点与屏幕阅读器标签。布局快捷键覆盖聚焦、分屏、关闭与标签切换。

独立窗口的生命周期、跨窗口共舞和多面板性能边界待定。
